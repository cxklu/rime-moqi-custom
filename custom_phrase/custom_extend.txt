# custom_extend.txt → cn_dicts_common/custom_extend.dict.yaml
#
# 作用：调整系统已有词的候选排序 / 添加系统没有的词
#       默认权重 500000（高于系统词频）
#
# 格式：
#     词	← 自动生成辅码，默认权重 500000
#     词	权重	← 自动生成辅码，指定权重
#     码长	ma;um; chang;pn;	500000	←指定多音字的读音，可从生成的yaml复制过来
# workflow: 编辑此文件 → python Rime词库管理.py → 重新部署 Rime
#
# 不要放单字：单字系统已有、混在几万同音字里，500000 的权重会把它硬顶到同音字
# 第一位且固定排序，既盖掉系统按词频排好的序列，也影响整句输入。
# 想让某个单字靠前，应该用简码（custom_short.txt），或在候选里直接补辅助码。
